# ak-archive-assets

Operator art, icons and other game assets for
[Arknights Archive](https://github.com/steve1316/ak-archive), served over raw.githubusercontent.com.

**Status: empty.** Nothing has been published yet. The tree is written by `tools/assets/` in the site
repository, not by hand.

Assets are extracted from community mirrors of the Arknights game files and re-encoded to WebP. Paths are
derived from the operator id and asset kind rather than looked up, so an `assets-manifest.json` at the root
records which assets actually exist.
